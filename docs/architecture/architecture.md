## 稀疏矩阵格式

### CSR (Compressed Sparse Row)

```
原始矩阵:          CSR 存储:
┌─────┬─────┐     values:      [1, 2, 3, 4, 5]
│ 1 0 2 │     col_indices: [0, 2, 1, 2, 3]
│ 0 3 4 │ =>  row_ptrs:    [0, 2, 4, 5]
│ 0 0 5 │     (第0行: [0,2), 第1行: [2,4), 第2行: [4,5])
└─────┴─────┘
```

### ELL (ELLPACK)

Column-major 存储实现完全合并访存。

---

## Kernel 选择策略

| 条件 | Kernel | 说明 |
|:-----|:-------|:-----|
| `avg_nnz < 4` | Scalar CSR | 单线程/行，最小开销 |
| `skewness < 10` | Vector CSR | Warp 协作，均匀分布 |
| `skewness >= 10` | Merge Path | 完美负载均衡 |
| ELL 格式 | ELL Kernel | 完全合并访存 |
