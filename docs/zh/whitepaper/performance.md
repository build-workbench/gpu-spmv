# 性能分析

## 基准测试方法

### 测试环境

| 组件 | 规格 |
|:-----|:-----|
| GPU | NVIDIA RTX 3090 (Ampere, SM 8.6) |
| 理论带宽 | 936 GB/s |
| CUDA 版本 | 12.0 |
| CPU | AMD Ryzen 9 5900X |
| 操作系统 | Ubuntu 22.04 LTS |

### 指标

- **执行时间**：10 次预热后 100 次运行的中位数
- **有效带宽**：`(读取字节数 + 写入字节数) / 时间`
- **利用率**：`有效带宽 / 理论带宽`

### 矩阵测试集

| 矩阵类型 | 描述 | 生成方法 |
|:---------|:-----|:---------|
| 对角 | 仅对角线有非零元素 | 合成 |
| 均匀 | 随机均匀分布 | `sprand(n, n, density)` |
| 幂律 | 无标度分布 | `sprand(n, n, density, 'power')` |
| 带状 | 带状矩阵 | 合成 |
| 真实世界 | SuiteSparse 矩阵 | 下载 |

## 内核性能对比

### 按矩阵模式

| 模式 | 规模 | 非零元素 | Scalar | Vector | Merge | ELL |
|:-----|:-----|:---------|:------:|:------:|:-----:|:---:|
| 对角 | 100K | 100K | 37.2% | 69.1% | 72.4% | 74.8% |
| 均匀 | 100K | 5M | 41.5% | 71.8% | 70.9% | 82.3% |
| 幂律 | 100K | 5M | 32.1% | 45.6% | 69.2% | 34.7% |
| 带状 | 100K | 5M | 28.4% | 64.9% | 58.1% | 41.2% |

**关键观察**：

1. **ELL 在均匀矩阵上表现最佳** (82.3%)，得益于合并访存
2. **Merge Path 在不规则模式中最稳健**
3. **Scalar CSR 仅对极稀疏矩阵有效**

### 按矩阵规模

| 规模 | 非零元素 | Scalar | Vector | Merge | ELL |
|:-----|:---------|:------:|:------:|:-----:|:---:|
| 10K × 10K | 500K | 42.1% | 70.2% | 68.5% | 78.3% |
| 100K × 100K | 5M | 36.7% | 68.7% | 71.5% | 73.7% |
| 1M × 1M | 50M | 34.8% | 65.5% | 70.8% | 71.2% |
| 10M × 10M | 500M | 33.2% | 62.1% | 69.4% | 68.9% |

**扩展性分析**：

- 所有内核在大规模时保持 >60% 利用率
- Vector CSR 在 10M 时略有下降（L2 缓存压力）
- Merge Path 保持一致性能

## 性能优化建议

### 1. 矩阵格式选择

```cpp
// 对于均匀矩阵，转换为 ELL
if (is_uniform(csr)) {
    ELLMatrix* ell = csr_to_ell(csr);
    // 使用 ELL 内核获得更好性能
}
```

### 2. 批处理

对于多次 SpMV 操作，复用配置：

```cpp
SpMVConfig config = spmv_auto_config(csr);

for (int i = 0; i < num_iterations; i++) {
    spmv_csr(csr, x[i], y[i], &config, n);
}
```

### 3. 内存预分配

预分配输出向量避免重复分配：

```cpp
CudaBuffer<float> y(num_rows);  // 一次分配
for (auto& x : inputs) {
    spmv_csr(csr, x, y.device_ptr(), &config, n);
    // 处理 y...
}
```
